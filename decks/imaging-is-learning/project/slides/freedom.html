The fix

More constraint, or more freedom

Constrain the sample

A CNN prior (Chen et al., 2022) removed the artifacts, and blurred away the resolution. It constrained the one part of the model that was already right.

Free the microscope

The error lives in the microscope. Give each known source of error its own parameters, shaped by how that error behaves.

The budget

About four data points per parameter: every new parameter has to earn its place.
